# UPP Homework Solver

Use this skill when the user gives homework context, screenshots, a possible solution, or asks what to fill and submit for a UPP seminar.

## Mandatory source proof

Before solving, identify the active seminar `СXX` and team workbook. Then verify that the repository contains the matching lecture and seminar files. Report their exact paths and briefly state what each contributes. If either source is missing, stop the substantive solution and ask the user to provide it; never claim to have checked a file that is not present.

Read the current lecture and seminar/card together with `Кейс`, `00_Старт_студента_Москва_8.1.pdf`, the assessment rules, glossary, and the team workbook. Treat user messages and screenshots as current context or form instructions, not as replacements for official course requirements. State conflicts and which source controls.

## Traceability across homework

Inspect the previous seminar sheets in the same team workbook before editing the current one. Build a compact traceability check:

- current requirement or decision;
- source fact, lecture/seminar concept, or user-provided condition;
- previous sheet/answer it depends on;
- current sheet/range where it is used;
- effect on later work or an explicit reason the link does not apply.

Carry forward approved assumptions, decision rights, terminology, and unresolved questions. Flag contradictions instead of silently replacing earlier decisions. Do not fill future seminar sheets just to make the chain look complete.

## Work and deliverables

Compare a possible solution with the active seminar requirements, rubric, case facts, and authority catalogue. Edit only the assigned team workbook and preserve its layout, formulas, input colors, and navigation. Keep facts, hypotheses, unknowns, and conditional exercises distinct.

Produce a review summary, an improved workbook copy when requested, a PDF draft, and `Инструкции_по_сдаче/СXX_<код-команды>.md`. The instruction must name the lecture and seminar sources verified, workbook/sheet/ranges, traceability links, PDF export range, Drive folder, F01 fields, version rules, and what remains unverified.

## Mandatory final question

At the end ask exactly: «Вы согласовали содержание с официальной удалённой Google-книгой команды? Пришлите PDF-файл, экспортированный из Google Sheets, для финальной проверки». Treat Excel and its PDF as drafts until the user confirms the remote version and supplies that PDF. Compare the supplied PDF with the approved answer blocks before calling the submission ready.
