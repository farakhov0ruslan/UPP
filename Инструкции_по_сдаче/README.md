# Инструкции по сдаче

Здесь хранится инструкция для каждого завершённого семинара. После подготовки очередного `СXX` нужно создать или обновить файл `СXX_<код-команды>.md`.

Каждая инструкция должна содержать:

- путь к итоговой книге и листу с ответами;
- диапазон, который нужно экспортировать в PDF, и исключённые служебные строки;
- имя и путь итогового артефакта;
- папку Drive для загрузки и ссылку на форму сдачи;
- значения обязательных полей формы;
- правила для второго PDF, `.pod`, исправлений и версии;
- финальную проверку доступности ссылки и сохранения подтверждения отправки.

Порядок для отправляющего участника: скачать итоговый PDF из папки артефактов, загрузить его в командную папку сдач, открыть форму `F01`, вставить ссылку на PDF, заполнить обязательные поля и сохранить подтверждение. Локальный путь к файлу в форме не используется.

`F01` предназначена для сдачи результата, `F02` — для перекрёстной проверки. Если преподаватель присылает новый дедлайн или уточнение, его нужно зафиксировать в инструкции конкретного семинара с указанием источника.

## Обязательное завершение

Перед финальной отметкой нужно спросить пользователя: «Вы согласовали содержание с официальной Google-книгой команды? Пришлите PDF, экспортированный из Google Sheets, для финальной проверки». Локальный Excel и PDF из него считаются черновиком. Финальная инструкция должна отметить, что Google Sheets PDF получен и проверен либо что пользователь отказался от этой проверки.
